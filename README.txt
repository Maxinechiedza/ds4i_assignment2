README.txt - what each file in project.zip contains
===================================================

project.zip holds one folder, ds4i_assignment2/, which is a copy of our
GitHub repository: https://github.com/Maxinechiedza/ds4i_assignment2
The rendered report is also online: https://maxinechiedza.github.io/ds4i_assignment2/


HOW TO RENDER THE REPORT
------------------------
1. Open ds4i_assignment2.Rproj in RStudio, or open a terminal in the folder.
2. Run:  quarto render
3. The report is written to docs/index.html (the website).

Rendering needs Quarto and the R packages tidyverse, knitr, scales and
patchwork. It reads the saved results in data/ and outputs/, so no model
is trained when rendering; it takes about two minutes. The model scripts
(R/ and Siamese*.R) also need keras3 and TensorFlow; they are only needed
to recreate the files in outputs/.

DATA
----
data/handwriting.rds      The assignment data from Amathuba: 25,000
                          simulated 28 x 28 greyscale digit images
                          (20 writers x 5 digits x 5 sessions x 50
                          replicates) with their metadata.
data/splits.csv           Split label for every image: split_main (by
                          session: train on sessions 1-3, validate on 4,
                          test on 5) and split_writer (whole writers held
                          out, 14/3/3). Written by R/00_data.R.
data/test_pairs.csv       The fixed 1,400 test pairs (same or different
                          writer) used to evaluate matching. Written by
                          R/00_data.R.


CODE
----
R/00_data.R               Loads the data and writes data/splits.csv and
                          data/test_pairs.csv (Jesse).
R/optimism_baseline.R     k-NN baseline on a random image split vs the
                          session-held-out split (Task 4, Jesse).
R/eval_embeddings.R       Scores PCA, CNN and Siamese embeddings on the same
                          test pairs (Task 6, Jesse).
R/cnn_functions.R         Shared CNN helpers: data splits, model builder
                          (1-3 convolution layers), training with early
                          stopping, learning-curve plot, and the encoder
                          shared with the Siamese network (Maxine).
R/cnn.R                   Trains the final 2- and 3-layer CNNs and writes
                          their test predictions, scores, training
                          histories and embeddings (Task 2, Maxine).
R/tune_cnn.R              CNN hyperparameter sensitivity: dropout, depth
                          and learning rate (Task 5, Maxine).
R/tune_cnn_valacc.R       Compares early-stopping rules (Task 5, Maxine).
R/tune_cnn_reg.R          Regularisation check for the 3-layer CNN
                          (Task 5, Maxine).
R/cnn_digit_session.R     Leave-one-session-out and digit-only CNNs
                          (Task 6, Maxine).
Siamese.R                 Siamese network: pair construction, training with
                          contrastive loss, evaluation, and results by digit
                          and session (Tasks 3 and 6, Nicole).
Tune_Siamese.R            Siamese hyperparameter tuning and the final tuned
                          model (Task 5, Nicole).
Siamese_Unseen_Writers.R  Siamese network tested on writers left out of
                          training (Task 3, Nicole).
R/.gitkeep, data/.gitkeep, outputs/.gitkeep
                          Empty files that keep these folders in git.
